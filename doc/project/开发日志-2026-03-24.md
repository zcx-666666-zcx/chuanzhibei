## 数据库表设计（2026-04-04，对齐微信小程序 + JPA）

### 设计目标

- 以小程序 **首页 / 沉浸 / 我的** 及二级页所需数据为主线，与 `chuanzhiback/demo` 中 **Entity 表名、字段命名（蛇形）** 一致，便于 Hibernate 与手工 SQL 对照。
- 提供 **可重复执行的 SQL**（`CREATE TABLE IF NOT EXISTS`），并在后端启动时可选自动执行。

### 表清单与业务含义

| 表名 | 对应实体 / 说明 | 主要支撑的小程序能力 |
|------|-----------------|----------------------|
| `users` | `User` | 注册登录、个人中心资料与头像 URL |
| `news` | `News` | 首页文化热点、新闻列表/详情、搜索、通知聚合 |
| `heritage` | `Heritage` | 非遗名录与详情、推荐非遗、收藏关联 |
| `inheritor` | `Inheritor` | 传承人名录 |
| `video` | `Video` | 技艺视频列表 |
| `activity` | `Activity` | 活动列表与报名 |
| `banner` | `Banner` | 首页轮播 |
| `user_collections` | `UserCollection` | 我的收藏、非遗详情收藏 |
| `user_bookings` | `UserBooking` | 我的预约、活动/体验预约 |
| `ar_experience_records` | `ARExperienceRecord` | 沉浸 Tab 体验记录、`POST /api/ar/history` |
| `ar_experience` | `ArExperience` | 历史 AR 体验条目实体（与前台「AR 项目」POJO 并存） |
| `ar_project` | **仅 SQL，暂无 JPA** | 可选：将 AR 项目从内存改为落库时的预留表 |

### ER 关系（文字说明）

- `user_collections.user_id`、`user_bookings.user_id`、`ar_experience_records.user_id` → `users.id`（`ON DELETE CASCADE`）。
- `video.inheritor_id` → `inheritor.id`（逻辑关联，脚本未加强制外键，避免初始化顺序问题）。
- `user_collections.heritage_id`、`收藏接口` → `heritage.id`（逻辑关联）。

### 自动化脚本位置与行为

| 项 | 说明 |
|----|------|
| **SQL 文件** | `chuanzhiback/demo/src/main/resources/schema-bootstrap.sql` |
| **执行类** | `com.example.demo.config.SchemaBootstrapRunner`（`ApplicationRunner`，应用启动完成后执行） |
| **开关** | `app.db.schema-bootstrap.enabled`：`application.properties` 默认 `false`；**`application-dev.properties` 默认 `true`**；可用环境变量 `SCHEMA_BOOTSTRAP` 覆盖 |
| **幂等** | 全部为 `CREATE TABLE IF NOT EXISTS`；已存在的表不会删除或覆盖 |
| **与 Hibernate** | 开发环境 `spring.jpa.hibernate.ddl-auto=update` 时，Hibernate 会先同步实体表结构；随后脚本再执行，对已存在表为 no-op，用于统一 DDL 文档与空库兜底 |

### 生产与校验模式注意

- 生产若使用 `spring.jpa.hibernate.ddl-auto=validate`，**必须先具备完整表结构**（执行一次 `schema-bootstrap.sql` 或由 DBA 按该文件建库），否则 Hibernate 在启动早期即失败，Runner 来不及补救。
- 生产建议保持 `app.db.schema-bootstrap.enabled=false`（默认），由发布流程显式执行 SQL 或迁移工具。

### 手工执行示例

```bash
mysql -h127.0.0.1 -uroot -p intangible_heritage < chuanzhiback/demo/src/main/resources/schema-bootstrap.sql
```

### 与旧 `schema.sql` 的关系

- 根目录下历史 `schema.sql` 已标注：**请以 `schema-bootstrap.sql` 为准**，避免与 JPA 实体列名不一致（如旧版 `inheritor.avatar` 与实体 `image_url` 等差异）。
