## 〇、约定与名词

| 项 | 说明 |
|----|------|
| **API 根路径** | 小程序 `utils/config.js` 中 `API_PREFIX = '/api'`，完整请求地址为 `{baseUrl}/api` + 下文路径（`baseUrl` 默认 `http://localhost:8001`，可 `wx.setStorageSync('apiBaseUrl', ...)` 覆盖）。 |
| **静态资源** | 业务图片/视频等多为 `{baseUrl}` + 相对路径（如 `/uploads/...`），前端用 `buildStaticUrl()` 拼接。 |
| **统一响应** | 后端 `Result<T>`：`{ success, message, data }`；失败时 `success: false`，前端需统一解析。 |
| **鉴权** | 需登录接口在请求头携带 `Authorization: Bearer <token>`（由 `utils/util.js` 从 Storage 读取）。 |
