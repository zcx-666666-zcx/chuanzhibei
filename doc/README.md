# 文档总目录

本目录用于集中管理项目说明、部署指南、设计方案、内部计划和本地原始材料，避免文档散落在仓库根目录。

## 分类说明

- `project/`：项目总览、迭代规划、开发日志
- `deploy/`：生产部署、后台管理部署
- `specs/`：专题页、产品设计方案
- `internal/`：本地开发计划、执行记录、内部过程文档
- `archive/`：本地原始文档、历史材料归档
